Sideband Comments

Register local project folders and the name shown on your comments. Markdown files stay unchanged; comments are saved in each project's .comments folder.

First install the Native Messaging host using the instructions in docs/chrome.md. In Chrome's extension details, enable Allow access to file URLs.

Choose the same project root used by VS Code or Obsidian so all clients share one comment store.

Connecting to the local host…

Only registered folders are available to the local host. Files and comments are processed on your computer. This extension does not upload documents.
