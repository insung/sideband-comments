# Sideband Comments for VS Code

Shows shared `.comments/threads/*.jsonl` review threads in the VS Code editor and in a dedicated **Comments** view in the Secondary Side Bar. It supports comments, replies, resolve/reopen, re-anchoring, external JSONL reload, and file relocation without MCP or agent integration.

Select text and run **Sideband Comments: Add Comment on Selection** from the editor context menu. The extension prompts for the comment immediately, persists it to JSONL, expands the inline thread, and opens the Sideband Comments view.

See the repository root README for architecture, development, and Obsidian installation instructions.
